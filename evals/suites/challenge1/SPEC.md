# challenge1 grading spec

What the answer key (generated by /setup-evals, never committed) must check. The task is in
`prompt.md`; this file only says how to grade it.

- **Function:** `evaluate(expr: str) -> Fraction`, called with one string argument.
- **Pass:** a `fractions.Fraction` equal to the exact value (an `int`, `float` or anything else is
  a failure, even if numerically equal). For invalid input: raising `ValueError` or a subclass.
  Any other exception, a returned value for invalid input, or a timeout is a failure.
- **Timeout:** 2 seconds per call (`TIMEOUT = 2`).
- **No stress test.**

Hidden tests: at least 15 cases (40+ recommended), covering every category below. Work out each
expected value by hand from `prompt.md`, not by running the reference. Name the category ids in
the `hidden_tests.py` docstring.

- [precedence] binary operator precedence and left-associativity, parentheses, whitespace
- [power-assoc] right-associative `^`, and `^` binding tighter than `*` and `/`
- [unary] unary `+`/`-`, repeated unary operators, unary minus versus `^` on both sides
- [exact] exact rational results, decimal literals converted exactly, zero and negative exponents
- [err-arith] division by zero (including via a negative power of zero), non-integer exponents
- [err-syntax] empty or blank input, dangling operators, unbalanced parentheses, implicit
  multiplication, unknown operators or characters
- [err-literal] malformed number literals

Mutants (at least 5): for example a left-associative `^`, unary minus binding tighter than `^`,
float instead of exact conversion, `ZeroDivisionError` escaping, accepting `3.` or `.5`.
