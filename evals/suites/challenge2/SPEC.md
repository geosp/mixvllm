# challenge2 grading spec

What the answer key (generated by /setup-evals, never committed) must check. The task is in
`prompt.md`; this file only says how to grade it.

- **Function:** `choose_box(items, boxes)`. Arguments arrive as lists (JSON), so a judge must
  accept lists where the prompt says tuples, in inputs and in the returned value.
- **Pass, when a box fits:** a 2-element result whose first element is the expected box name
  (smallest volume, ties to the earlier box) and whose placements are physically valid: every
  item exactly once, each size a permutation of the item's dimensions, inside the box, no two
  items overlapping (touching allowed).
- **Pass, when nothing fits** (or `boxes` is empty): `None`.
- **Timeout:** 10 seconds per call.

Hidden tests: at least 15 cases, covering every category below. Derive expected box names by hand
or with a solver independent of the reference. Name the category ids in the `hidden_tests.py`
docstring.

- [single] one item that fits several boxes: the smallest wins
- [rotation] an item that only fits rotated
- [volume-trap] items whose total volume fits a box although no arrangement does
- [stacking] several identical items that fill a box exactly
- [multi] three or more different items
- [tie] two boxes of equal volume: the earlier one wins
- [none-fits] no box can hold the items, and an empty `boxes` list
- [empty-items] no items: the smallest box with an empty placement list

**Stress test** (`stress_cases.py`): a few thousand random tight single-box instances (2–4 items,
small integer sizes, total item volume between 60% and 100% of the box), generated from a fixed
seed. `expected` is whether the items fit (from the reference). `judge_stress` gives: `missed` for
`None` when a fit exists, `impossible` for a placement when none exists, `invalid` for a placement
that breaks the rules, `ok` otherwise. `brute.py` must decide fit/no-fit independently of the
reference (e.g. a plain exhaustive search over a grid), at least for small boxes.

Mutants (at least 5): for example no rotations, overlap check that rejects touching items,
greedy first-fit placement, volume-only feasibility, the wrong tie rule.
